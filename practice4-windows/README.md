# Практическая работа № 4 · вариант 3

Учебная наземная станция и эмулятор БПЛА обмениваются MAVLink 2 по UDP через `127.0.0.1`. Порт НСУ по умолчанию — **14540**.

## Запуск

Откройте `Practical_04_MavlinkGroundStation.exe` и нажмите **Открыть UDP-порт**. Затем нажмите **Запустить БПЛА** в этом же окне или откройте `Practical_04_UavSimulator.exe` и нажмите **Запустить БПЛА** там. Для одного сеанса достаточно одного эмулятора. Если меняете порт, укажите одинаковое значение в обеих программах.

Для демонстрации задайте **80 м**, нажмите **Взлёт** и подтвердите команду. После `COMMAND_ACK` статус покажет результат, а график — фактическое изменение высоты от точки старта. **Стоп** удерживает текущую позицию, **Посадка** начинает снижение.

## Проверка отказов

| Действие | Что должно произойти |
| --- | --- |
| Повредить пакет | Счётчик ошибок увеличится. Причина CRC появится в сетевом журнале. Повреждённые данные отбрасываются. |
| Пропустить 2 пакета | Счётчик пропусков увеличится на два после следующего принятого пакета. Повреждённый пакет тоже может образовать пропуск в последовательности. |
| Пропустить ACK → Посадка | Следующая команда останется без подтверждения. Через 3 с появится сообщение о тайм-ауте. |
| Сбой датчика | Позиционная телеметрия приостановится. HEARTBEAT продолжит поступать со статусом аварии. Повторное нажатие снимет сбой. |
| Отключить БПЛА | Через 3 с появится красный статус «Связь потеряна». Кнопки полёта заблокируются, а время последнего пакета останется на экране. |
| Снова запустить БПЛА | Появится статус «Связь восстановлена», кнопки снова станут доступны. |

Подключение, команды полёта и управление эмулятором находятся в левой панели. Справа под графиком доступны вкладки **История телеметрии**, **Сетевые события** и **Журнал команд**. История телеметрии содержит до 200 строк с интервалом не менее одной секунды. График хранит до 300 точек. Звук можно отключить переключателем в шапке.

Эффект ошибки — мемный «Sad Trombone» (Sad Tromboner, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Sad_Trombone.wav), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)). Запись обрезана, сведена в моно и преобразована в 22,05 кГц. Сигналы подключения, принятия команды и потери связи синтезированы для проекта.

## Сборка

Откройте `CMakeLists.txt` в Qt Creator с комплектом Qt Desktop, в котором установлены Widgets, Network, Charts и Multimedia. CMake собирает обе программы. Файл `.pro` собирает НСУ со встроенным эмулятором.

Обмен рассчитан на локальный учебный стенд с одним эмулятором. Парсер покрывает четыре неподписанных сообщения MAVLink 2 из задания — HEARTBEAT, GLOBAL_POSITION_INT, COMMAND_LONG и COMMAND_ACK. Форматы полей сверены с [описанием сообщений MAVLink](https://mavlink.io/en/messages/common) и [правилами сериализации](https://mavlink.io/en/guide/serialization).
